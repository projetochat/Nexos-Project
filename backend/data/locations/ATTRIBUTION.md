# Atribuição dos dados de localidades

## GeoNames

Este produto contém dados adaptados do GeoNames (`countryInfo`, `admin1CodesASCII` e `cities500`), obtidos em 21/10/2026.

- Fonte: https://www.geonames.org/
- Downloads: https://download.geonames.org/export/dump/
- Licença: Creative Commons Attribution 4.0 — https://creativecommons.org/licenses/by/4.0/
- Alterações: seleção do recorte `cities500`, remoção dos registros brasileiros, normalização de nomes e conversão para o formato interno do Trixus.

O GeoNames fornece os dados “como estão”, sem garantia de precisão, atualidade ou completude.

## IBGE

As UFs e os municípios brasileiros foram derivados da Divisão Territorial Brasileira 2025, arquivo `RELATORIO_DTB_BRASIL_2025_MUNICIPIOS.xls`, disponibilizado publicamente pelo Instituto Brasileiro de Geografia e Estatística.

- Produto: https://www.ibge.gov.br/geociencias/organizacao-do-territorio/estrutura-territorial/23701-divisao-territorial-brasileira.html
- Download: https://geoftp.ibge.gov.br/organizacao_do_territorio/estrutura_territorial/divisao_territorial/2025/
- Alterações: seleção de UF, nome da UF, código municipal e nome do município; normalização e conversão para o formato interno do Trixus.
